# 模板清理清单

## 1. 用途

这份清单用于区分“当前只是模板遗留”与“已经决定保留”，避免后续开发把清理工作遗漏，或在错误时机做破坏性迁移。

## 2. 高优先级清理项

- 修复 `YukiMod/localization/zhs/characters.json` 的乱码或编码问题
- 把 README 从“模板说明”升级为“当前项目说明”
- 逐步确认 `YukiMod.json`、本地化文本、角色说明中的模板措辞是否还需要保留

## 3. 中优先级清理项

- 清点 `YukiMod/images/charui` 下的 `meilin` 命名资源
- 决定这些资源是短期保留、仅换显示文本，还是正式改名迁移
- 为将来替换模板素材预留更清晰的命名方案

## 4. 低优先级或可延后的项

- 全仓库范围的类名、资源名统一重命名
- 视觉素材完全替换
- 大规模删除模板残留目录

这些动作影响面大，适合在角色方向基本稳定后进行，而不是在项目刚起步时抢先处理。

## 5. 清理时的硬规则

- 先确认引用链，再改名或替换资源
- 不要因为名字里含 `meilin` 就直接判断成“可以删除”
- 若本轮只做功能推进，可暂时容忍模板资源存在，但要在说明里记录
- 若开始做正式迁移，应同步修改代码路径、资源文件名、文案和相关文档

## 6. 发布前至少应完成的事项

- 中文角色文案可正常读取
- README 不再把项目描述成纯模板
- 玩家可见的关键命名不再暴露明显的梅玲模板痕迹
- 已确定保留的模板资源有明确理由
