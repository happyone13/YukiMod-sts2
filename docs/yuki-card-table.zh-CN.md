# Yuki 卡牌草案表

说明：
- 统计口径里，`预见` 计入 `灵感`。
- 一张卡可以同时属于多个流派，所以下面流派统计会重复计数。
- `Token` 单独记为稀有度。
- 原始文本里有一处粘连记录，未强行拆分，见文末备注。

## 评分口径

- `1费标准卡≈1分`，换算基准为：`11` 伤害 = `9` 格挡 = `2.5` 抽牌 = `2` 费 = `8` 预见 = `8` 月影伤害 = `2` 凝聚 = `2` 力量 = `5` 临时力量 = `1/7` 居合。
- `灵感：`、`黑云：` 后面的额外收益按 `0.5` 倍计分。
- 能力牌按 `3` 回合收益估算。
- 下回合收益先除以 `1.5` 再换算，例如“下回合获得 `3` 费”按“当前获得 `2` 费”计。
- 目前只计算上面列出的收益类型；姿态、检索、复制、保留、固有、减费、生成牌等其他收益暂不计分。
- 默认按未升级数值估算；范围伤害先按单体保守估算。
- `docs/yuki-card-table.xlsx` 是当前卡牌实现的权威来源；如果本 md 与 xlsx 冲突，以 xlsx 为准。
- `docs/yuki-card-table.xlsx` 中的 `评分` 列直接记录当前得分；不好稳定估算的牌暂时跳过。
- `docs/yuki-card-table.xlsx` 中的 `费用` 列按基础费用数字记录；若升级后变费，写入 `备注`。
- `docs/yuki-card-table.xlsx` 中的 `稀有度`、`种类`、`流派` 使用下拉选项，统计页按卡牌表自动计算。
- 代码实现和 `cards.json` 录入时，`消耗`、`固有`、`保留` 这类通用关键词默认依赖原版/框架自动追加，不需要在描述文本里重复手写；表格里保留这些字样只是为了记录卡面效果和升级变化。
- 若本 md、旧代码、旧对话记录与 `docs/yuki-card-table.xlsx` 冲突，一律以当前 xlsx 为准；修卡前先回看表格，不要沿用旧记忆。

## 关键词与遗物

- 灵感：回合开始以外、抽卡以外的方式把卡牌加入手中，会解锁额外效果。
- 黑云：当你处于黑云姿态时触发卡的额外效果，否则进入黑云姿态。
- 黑云姿态：你的牌可以触发黑云效果，使用攻击牌以外的卡会退出黑云姿态。
- 凝聚：手中的月影费用+1，获得重放1；如果手中没有月影，获得一张月影。
- 月影：0费，造成5点伤害，其他攻击命中时伤害+1。（当前造成x点伤害）保留。
- 预见：观察牌组顶部x张卡牌，选择任意数量丢弃。
- 初始遗物：战斗开始时凝聚1。
