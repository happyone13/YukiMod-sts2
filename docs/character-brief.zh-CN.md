# 友纪角色简报

## 1. 文档用途

这份文档只记录当前已经确认、或者当前明确仍为空白的角色信息，避免后续开发把模板占位内容误当成正式设定。

## 2. 当前已确认信息

- 项目代号：`YukiMod`
- 当前角色名：`友纪 / Yuki`
- 当前代码角色 ID：`YukiMod`
- 性别设定：`Feminine`
- 当前主色：`#9DD9D2`
- 当前初始生命：`72`
- 当前初始卡组：空
- 当前初始遗物：空

## 3. 当前仍是占位的部分

- 角色核心机制
- 角色关键词体系
- 起始遗物
- 起始卡组
- 卡池方向
- 药水风格
- 完整世界观文本
- 正式中文展示名是否只保留“友纪”或另有副标题

## 4. 当前模板遗留事实

- 英文本地化仍在描述 “template character”
- 中文角色文案当前不可直接使用
- 多张 UI 图片仍保留 `meilin` 命名
- 当前角色资源更多是在证明“路径可接通”，不是在证明“角色风格已确定”

## 5. 暂定开发边界

在用户没有进一步明确设定前，后续工作应遵守以下边界：

- 不擅自写死大段角色背景设定
- 不擅自建立与梅玲完全相同的机制映射
- 不把模板文本直接润色后当成正式文案
- 可以为工程推进添加必要占位，但要在说明里标明其占位性质

## 6. 适合优先确认的内容

后续如果要真正开始做友纪内容，建议优先确认以下项目：

1. 友纪的战斗主轴是什么
2. 她是否需要独有资源条或姿态系统
3. 起始遗物想解决什么玩法问题
4. 第一批卡牌是偏启动、偏成长，还是偏控制
5. 视觉语义是沿用现有模板色系，还是整体重做

## 7. 使用规则

凡是涉及以下改动，先回看这份文档：

- 角色名与文本展示
- 起始属性
- 核心机制
- 卡牌/遗物/药水方向
- 视觉表达和 UI 命名

如果某次工作把这些内容从“未定”变成“已定”，请同步更新本文件。
